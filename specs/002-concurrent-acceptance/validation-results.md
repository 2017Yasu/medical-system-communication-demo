## 実装中に見つかり、修正した問題

- **ブラウザの HTTP キャッシュ**：`GET /Task/{id}` がブラウザにキャッシュされ、受付を始めるときや 412 の後の取り直しで古い応答（版）を返すことがあった（同時確定の繰り返しで検出）。`FhirClient` の要求に `cache: "no-store"` を付けて解消した。
- **エラー表示の消失**：操作の失敗の直後に行う一覧の取り直しが、成功するとエラー表示を消していた（S1 から存在）。取り直しの後にエラーを表示する順序に直した。

- `docker run --network none` での S2 の実行。
