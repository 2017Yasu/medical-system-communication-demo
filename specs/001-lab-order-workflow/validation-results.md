# 検証結果：S1 検体検査ワークフロー

**測定日**: 2026-10-01 ／ **環境**: WSL2（Linux）、Java 26（`--release 21` でビルド）、Docker 29、Chromium（Playwright 1.63）。
**対象**: `docker compose` と同じ構成の実行可能 JAR（ローカル起動）。手順は [quickstart.md](quickstart.md)。

## 実装中に見つかり、修正した問題

| 問題 | 発見のきっかけ | 修正 |
|---|---|---|
| gzip 圧縮された応答が、通信記録に圧縮されたまま記録される | ブラウザでの通信モニタ確認 | フィルタで展開して記録（単体テスト追加） |
| シーケンス図の行の空白部分を押しても反応しない | E2E の失敗 | 透明な当たり判定を追加 |
| 同じ ID の Subscription を複数の画面が同時に作ろうとして、後の画面が通知を受けられない | 全 E2E の連続実行での不安定 | 登録の競合を検知して再確認（単体テスト追加） |
| 看護師の画面に切り替えると、医師の画面の通知の受信が外れる | 自習モードの E2E | 両方の画面を配置したまま表示だけ切り替える |
| 自動ステップの判定で、後続の同種の通信により基準が先へずれる | 講演モードの E2E | 「最後に一致した記録」ではなく「基準より後で最初に一致した記録」を基準にする（単体テスト追加） |
| 患者の既定が「デモ 花子」になる（検索結果が更新日時の新しい順） | 実ブラウザでの E2E | 患者番号順に並べる |
| 通信の詳細の日本語が豆腐（□）になる | スクリーンショットの確認 | 等幅フォントに日本語フォントを追加 |
